# Level Up Notifications (port)

Port of *[RE_Kenshi] Level Up Notifications* (workshop 3701534964). A notice ("Mu: Melee Attack 12") when a player character's stat passes a whole
level, optionally only every Nth level. Polls stats twice a second; presentation only, not saved or hashed. **Observed** (2026-11-17, live Windows sandbox on origin/master f7ad84a35, driven by input): a fight posted "Mu: Dexterity 2" as Mu levelled.
