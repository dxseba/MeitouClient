## Robot spark

`robot-spark.png` is an unmodified copy of `PNG (Black background)/trace_01.png` from **Particle Pack 1.1** by **Kenney Vleugels (Kenney.nl)**.

- Author/source and CC0 declaration: https://kenney.nl/assets/particle-pack
- Download: the source page's free download button, archive `kenney_particle-pack.zip`; included `License.txt` confirms CC0.
- License: CC0 (https://creativecommons.org/publicdomain/zero/1.0/).
- Original dimensions: 512 × 512. Vertical white streak on black; runtime orange tint, additive blend, central 32% width sampled.
- Archive SHA-256: `b631d4b07f7002549fdcf155f01141ad482f79f3440e4e301eed49ce5f1d8958`.
- PNG SHA-256: `fb5857094cacdfaed6886ab48f545a13a64d6fe646030b124b2e334705d7f408`.

These public-domain textures are separate from the user's installed game assets. No Kenshi texture is included here.
